# Audio Files Directory

Place your audio files here. The following naming convention is used:

## Click Sound Effects
- `mun1.mp3` - Random click sound 1
- `mun2.mp3` - Random click sound 2
- `mun3.mp3` - Random click sound 3
- ... (add more as needed)

## First Click Sound (optional)
- `ganbaru.mp3` - Special sound played on the very first click

**Note:** File names must match the `audioFiles` array in `public/project.json`.
